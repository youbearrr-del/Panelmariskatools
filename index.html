Cara web chat membaca panel ini

Panel dan web chat memakai satu proyek Firebase (mariskaratnadewi), jadi semua perubahan tersinkron langsung.

Struktur data
system/config  (Firestore)
  maintenance: boolean
  maintenanceMessage: string
  announcement: string
  announcementType: "info" | "warning" | "danger"
  version: string
  updateUrl: string
  changelog: string
  forceUpdate: boolean
  forceLogoutAt: waktu ISO (string)
  flags: { namaFitur: boolean }

users/{id}  (Firestore, ditulis web chat + panel)
  id, name, email, role, color, bio, photo, joinedAt
  banned: boolean      (panel)
  muted: boolean       (panel)
  expiresAt: waktu ISO atau null  (panel)

presence/{id}  (Firestore, ditulis web chat)
  online: boolean, lastSeen: Timestamp

logs/{auto}  (Firestore, ditulis panel)
  type, action, detail, admin, time

messages/{id}, stories/{id}, media/{id}  (Realtime Database)

Aturan keamanan yang disarankan

Tempel di Firebase Console, bagian Firestore Database lalu Rules. Ganti email dengan email moderator Anda.

Firestore rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function isMod() {
      return request.auth != null
        && request.auth.token.email in ['mariskadm@mariskatools.app'];
    }
    match /system/{doc} {
      allow read: if request.auth != null;
      allow write: if isMod();
    }
    match /logs/{id} { allow read, write: if isMod(); }
    match /presence/{id} { allow read, write: if request.auth != null; }
    match /users/{id} {
      allow read: if request.auth != null;
      allow create: if isMod() || (request.auth != null
        && !request.resource.data.keys().hasAny(['banned','muted','expiresAt']));
      allow update: if isMod() || (request.auth != null
        && !request.resource.data.diff(resource.data).affectedKeys()
            .hasAny(['banned','muted','expiresAt']));
      allow delete: if isMod();
    }
  }
}

Yang perlu disiapkan

  1. Di Firebase Console proyek ini, buka Authentication, Sign-in method, lalu aktifkan Email/Password.
  2. Di Authentication, Users, klik Add user: email mariskadm@mariskatools.app dengan password akun moderator. Di halaman login cukup ketik mariskadm.
  3. Pastikan Realtime Database mengizinkan moderator menghapus messages, stories, dan media.
  4. Tambahkan domain tempat panel ini di-host ke Authentication, Settings, Authorized domains.
